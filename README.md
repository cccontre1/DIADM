# DIADM — Inteligencia Artificial para Diagnóstico Médico

Repositorio académico correspondiente al **Diplomado en Inteligencia Artificial para Diagnóstico Médico (DIADM), Pontificia Universidad Católica de Chile**.

Reúne trabajos prácticos desarrollados a lo largo del programa, mostrando una progresión desde el manejo de datos y señales fisiológicas hacia **machine learning, imágenes médicas, aprendizaje no supervisado, deep learning y modelos multimodales**.

> **Contexto académico:** algunos trabajos corresponden a actividades grupales. La composición de cada actividad se conserva en los notebooks originales y este repositorio no atribuye individualmente trabajos que fueron realizados en equipo.

## Estructura

| Carpeta | Enfoque |
|---|---|
| `01_Fundamentos_y_Datos` | Python aplicado, ECG y datos de salud |
| `02_Imagenes_Medicas` | Imágenes médicas y DICOM |
| `03_Machine_Learning` | Regresión, clasificación y SVM |
| `04_Aprendizaje_No_Supervisado` | PCA y K-Means |
| `05_Deep_Learning_y_Multimodal` | Segmentación cardíaca, ECG y Med-Gemma |

## Proyectos destacados

### Med-Gemma
`05_Deep_Learning_y_Multimodal/proyecto_medgemma.ipynb`

Proyecto académico orientado al uso de un modelo multimodal en un contexto de imágenes médicas y texto, con evaluación experimental.

### Segmentación cardíaca — ACDC
`05_Deep_Learning_y_Multimodal/segmentacion_cardiaca_acdc.ipynb`

Trabajo de segmentación de estructuras cardíacas en imágenes médicas utilizando el dataset ACDC. El notebook incluye trabajo con PyTorch.

### Clasificación de ECG
`05_Deep_Learning_y_Multimodal/clasificacion_ecg.ipynb`

Ejercicio de deep learning aplicado a señales ECG, con implementación en PyTorch.

### Análisis de imágenes médicas y DICOM
`02_Imagenes_Medicas/proyecto_imagenes_medicas.ipynb`

Trabajo práctico de procesamiento y exploración de imágenes médicas.

## Reproducibilidad

Los notebooks pueden requerir datasets externos o recursos descargados durante las actividades. Los datos no se incluyen en este repositorio. Antes de ejecutar un notebook, revisar sus primeras celdas para identificar los datos y dependencias necesarios.

## Nota de portafolio

Este repositorio funciona como **evidencia de formación especializada en IA aplicada a salud**. Su objetivo es mostrar la amplitud y progresión técnica del aprendizaje, mientras los proyectos de software independientes del portafolio principal demuestran implementación de soluciones de extremo a extremo.
